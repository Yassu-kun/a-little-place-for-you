# A Little Place For You

A personal 2D game project developed with Godot 4 and GDScript.

## About the project

The game includes an interactive garden, an explorable house,
scene transitions, interactive objects, and a mailbox system.

## Technologies

- Godot 4
- GDScript
- Scene-based development
- Interactive game objects
- Game-state management

## Planned improvements

- Refactor large scripts into reusable components
- Improve gameplay interactions
- Fix bugs and improve stability
- Add automated testing where practical
- Improve code organization and performance
