# A Little Place For You

Personal Godot 4 / GDScript game development project.

## Repository status

This repository contains the original GDScript and scene source, without personal photographs, audio, or third-party asset packs. The original game scenes are **not fully runnable** without those excluded resources.

A small, self-contained **clean demo** is provided in `scenes/safe_demo.tscn` and `scripts/safe_demo.gd`. It demonstrates player movement, mouse navigation, collection interactions, and procedural drawing without external media.

## How to run the clean demo

Open the repository with Godot 4, then open `scenes/safe_demo.tscn` and select **Run Current Scene (F6)**. The original project's default scene may require excluded resources.

## Technology

Godot 4, GDScript, scene-based architecture, interaction handling, and state management.
